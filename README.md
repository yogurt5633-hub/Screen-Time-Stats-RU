# ⏱️ Screen Time Stats (RU)

Узнайте, сколько времени вы сегодня провели в чате с ботом и кто лидирует на этой неделе ✨

Русский перевод расширения [Screen Time Stats](https://github.com/janzanaja188-cyber/Screen-Time-Stats). Автор: **maanfhun**.

## Как открыть
Нажмите на иконку волшебной палочки рядом с полем ввода и выберите **Время в чате**.
Карточка со статистикой откроется посередине экрана.

## Что в карточке
- **Сейчас** — живой таймер открытого чата. Кольцо вокруг цифр показывает прогресс к дневной цели.
- **Итого за 7 дней** — сумма минут и сравнение с прошлой неделей: ▲ больше, ▼ меньше.
- **По дням** — столбчатый график. Нажмите на столбец, чтобы увидеть цифры за этот день. Крайний правый столбец — сегодня.
- **Рейтинг** — пьедестал из трёх персонажей. Можно переключать между *дольше всего общались* и *больше всего сообщений*.

## Когда идёт отсчёт
Таймер работает, пока открыт чат, и сам останавливается, если:
- вы переключились в другое приложение или выключили экран — сразу;
- вы бездействуете дольше заданного времени — пауза, при любом действии отсчёт продолжится;
- вы перешли к другому персонажу — время старого сохраняется, начинается отсчёт нового.

Сообщения считаются только от бота. Свайпы (перегенерация ответа) не добавляют лишнего, поэтому цифры честные.

## Настройки
Extensions → **⏱️ Screen Time Stats**
- *Пауза при бездействии* — от 1 до 60 минут, по умолчанию 5.
- *Дневная цель* — через сколько минут кольцо заполнится.
- *Скрывать имена персонажей в рейтинге* — удобно перед скриншотом для друзей.
- *Анимации и эффекты* — можно выключить для простого вида.

## Где хранятся данные
В файле настроек вашего аккаунта SillyTavern. Они сохранятся, даже если закрыть вкладку, очистить кэш или зайти с другого устройства.
Все цвета берутся из текущей темы: смените тему, и карточка поменяется вместе с ней 🎨

## Установка
Extensions → **Install Extension** → вставьте ссылку на этот репозиторий:

```
https://github.com/yogurt5633-hub/screen-time-stats-ru
```

После установки один раз обновите страницу. Если у вас стоит оригинальная версия расширения, удалите её, чтобы время не считалось дважды.
